# 기린로그 메뉴바 앱 — 배포 채널

macOS 메뉴바 메모 앱 GirinLog의 릴리즈 저장소입니다.
소스 코드는 별도의 private 레포에서 관리됩니다.

## 설치
1. [최신 릴리즈](../../releases/latest)에서 `GirinLog-x.y.z-arm64.dmg` 다운로드
2. 열어서 응용 프로그램 폴더로 드래그

### "손상되었기 때문에 열 수 없습니다" 오류가 뜨는 경우
서명되지 않은 앱을 브라우저로 내려받으면 macOS가 격리 속성을 붙여 이 메시지가 나옵니다.
실제 손상이 아니며, 터미널에서 아래 한 줄로 해결됩니다:

```bash
xattr -dr com.apple.quarantine /Applications/GirinLog.app
```

## 업데이트
설치 후에는 앱이 이 레포의 릴리즈를 자동 감지해 팝오버에 업데이트 버튼을 표시하며,
클릭 한 번으로 재설치 없이 새 버전으로 교체됩니다 (인앱 업데이트는 격리 속성 문제 없음).
